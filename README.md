# project_sprint7

TripleTen, proyecto de fin sprint 7, desarollo de software

Este proyecto es una aplicación web que usa streamlit para desplegarla en web.

Podemos ver un análisis sencillo de los vehículos usados y la relación entre el odómetro y el precio del vehiculo.

La aplicación te permite seleccionar entre un grafico de dispersión y un histograma.
